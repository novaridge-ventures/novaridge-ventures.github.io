These repositories are public. They are not on the npm or NuGet public registries yet, so install them from GitHub as shown in each README. The same SARS tables power the SA income tax, provisional tax and VAT calculators on this site.

novaridge-sa-tax

Node.js helpers for South African PAYE estimates, provisional tax (IRP6) and VAT, using the official SARS 2025/26 and 2026/27 tables.

View on GitHub

npm install github:novaridge-ventures/novaridge-sa-tax

Novaridge.Webhooks

A .NET 8 library for HMAC-SHA256 webhook signatures with replay protection. It is the reusable core of our free ePOD webhook sample.
